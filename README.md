# Matchbook Labs — portfolio

Source for https://jayjex.github.io/portfolio/, the Matchbook Labs landing page.
19 paid digital products on Getly, 3 MCP servers on pay-per-call rails, and open
source Solana/EVM tooling. Solo operation: everything listed is built, deployed,
and supported from one headless Linux box.

## What's here

- `index.html` — the whole site in one file: static HTML, CSS, vanilla JS. No
  framework, no build step.
- `audit.js`, `nojs.js` — progressive enhancement. The page works with
  JavaScript off.
- `sitemap.xml`, `robots.txt` — indexing config. The sitemap goes to Bing via
  IndexNow.
- `7b4ef1791116046e7c699646367d7981.txt` — IndexNow key file, required at the
  site root for submission auth.

## Use it

Clone the repo, edit `index.html`, push to `main`. GitHub Pages serves the site
from the branch, nothing to install or compile.
